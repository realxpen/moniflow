# @moniflow/moniguard

MONI Guard is MONIFlow's deterministic financial safety and policy boundary. It is not an LLM.

AI may help form a plan, but AI must never decide that a plan can bypass safety controls. A later rule engine will produce auditable checks and an `ALLOW`, `REVIEW`, or `BLOCK` verdict. Phase 1 defines only these foundational contracts; it does not implement the rule engine.
